# Call Log Vault v1.2.0

The honest delete release, plus a full visual polish.

**Deletes that stay deleted.** Until now, a call you deleted from the vault could quietly return: it still sat in your phone's call log, and the next sync copied it back. That is fixed properly. Deleting now saves a scrambled fingerprint of the call (a one-way hash that cannot be read back into a number), and every sync, backup import and watch folder check refuses fingerprinted calls. What you delete stays deleted.

**Two kinds of delete, your choice each time.** Long press in a person's timeline to select one or many entries. The confirmation offers **Vault only** (your phone's call log keeps the call) or **Vault and phone log** (the call is also removed from the phone's call log and disappears from the dialer). Delete all for a whole number works the same way.

**A proper face lift.** Every popup is now the app's own dialog design instead of the stock Android one, including the backup schedule picker, which is now a clean selectable list. The settings switches are a custom drawn toggle, smooth and themed, replacing the stock switch. Status is grouped into readable cards, AMOLED gets real layering (dark cards over true black instead of one flat black), and the drawer, person screen and lists share one consistent rhythm.

Nothing about the vault, backups, formats or permissions changed. Same 4 permissions, no internet. This release installs over v1.1.0 and keeps your existing vault.
