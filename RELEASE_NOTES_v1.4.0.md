# Call Log Vault v1.4.0

This release closes out GitHub issues #12 to #14, all three requested by a user of the app. Thank you for filing them. It also adds new privacy options and a What's New popup. Version 1.3.0 to 1.3.3 were test builds that were never published, so everything since the last public release, v1.2.9, is in here.

One call, not one calls (issue #12). A person with exactly one saved call now reads "1 CALL" instead of "1 CALLS".

One person, one entry (issue #13). A person saved with and without a country code no longer shows up as two people. If the same person appears as, say, +1 22233 and 22233, the People page now groups them into one entry, with the longest number shown and the most recent name kept. No calls are merged or lost, the grouping only changes how people are shown.

Smoother side scroller (issue #14). The slim pill on the right edge now fades away after you stop scrolling, shrinking smoothly in overall size as it goes, instead of squeezing sideways. When you scroll again it grows back gently, not with a jerk. It still grows while you hold it and settles back when you let go.

Calm solid colours, no glass look. The pills now use plain solid colours taken from the File Master app: white on light screens, dark grey on dark screens, near black on AMOLED screens, each with a thin hairline edge. The glassy gradient look is gone. The scroller is also easy to see on white screens now, where it used to blend into the background.

Privacy options, in the drawer under PRIVACY. Both are on by default, so nothing changes unless you turn them off.

Show call details. Turn this off and the per person details disappear: first call, last call, total calls and total talk time. People rows then show just the number, and a person's screen keeps its name, number, Call button, Restore button and delete action. Turn it back on and everything returns at once. This only hides what is shown, it never deletes any calls.

Show People menu. Turn this off and the whole People section disappears from the drawer, and the app stays on the Call log page. Your people data stays safe in the vault, only the menu is hidden. Turn it back on and People returns.

What's New popup. After each update, a short popup appears once, in plain language, telling you what changed. It never repeats for that version, and you can open it again anytime from "What's new" in the drawer.

Same 4 permissions, no internet, same backup format. This release installs over v1.2.9 and keeps your existing vault.
