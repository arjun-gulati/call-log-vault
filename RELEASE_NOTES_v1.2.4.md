# Call Log Vault v1.2.4

New: swipe down to sync, requested as GitHub issue #5. On the Call log and People pages, pull down from the very top of the list to sync, the same gesture as refreshing a page in a browser. A reload badge winds up as you pull, with a label under it that reads "Pull to sync", then "Release to sync" once the pull is far enough. The badge spins with "Syncing…" while the sync runs, and a confirmation message names the result when it lands, the same one the Sync now button shows. It uses the same sync as that button, and if a sync is already running it simply reflects that one instead of starting another.

Nothing else changed. Same 4 permissions, no internet, same vault and backup format. This release installs over v1.2.2 and keeps your existing vault.
