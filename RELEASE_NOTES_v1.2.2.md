# Call Log Vault v1.2.2

One fix, reported as GitHub issue #4: in the Backup schedule menu, tapping an option saved the choice, but the menu itself never closed and kept showing the old selection, so the change only appeared after backing out of the menu. Tapping an option now selects it and closes the menu right away. The Restore to Dialer choice menu uses the same dialog and had the same problem, so it is fixed too.

Nothing else changed. Same 4 permissions, no internet, same vault and backup format. This release installs over v1.2.1 and keeps your existing vault.
